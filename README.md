# VRM2MoBu_Bone_Renamer

注意！　このアドオンはまだ作りかけです

## 1. インストール手順

### 方法A: Blender の設定からインストール（推奨）
1. Blender を起動します。
2. 上部メニューの **編集 (Edit) > プリファレンス (Preferences)** を開きます。
3. 左側の **アドオン (Add-ons)** または **拡張機能 (Extensions)** タブを選択します。
4. 右上のドロップダウンメニュー（▼アイコン）から **ディスクからインストール... (Install from Disk...)** を選択します。
5.  [bone_batch_renamer.zip] を選択してインストールします。
6. 一覧で **Bone Batch Renamer** にチェックを入れて有効化します。



## 2. 基本的な使い方

### STEP 1: パネルを開く
1. 3Dビューポートで **Nキー** を押し、右側のサイドバーを展開します。
2. **Bone Renamer** タブをクリックします。

### STEP 2: 対象アーマチュアの指定
- 3Dビューでモデル（アーマチュア）を選択します。
- パネル最上部に「選択中: [アーマチュア名]」と表示されます（明示的にオブジェクト指定ボックスから選択することも可能です）。

### STEP 3: ボーン名リストの作成（2通りの方法）

#### 方法1: 現在のボーンから自動読み込みして編集
1. **「現在のボーンを読み込む」** ボタンを押します。
2. アーマチュア内の全ボーンが一覧に読み込まれ、変更前/変更後に同名がセットされます。
3. リスト内の「変更後」テキストフィールドを編集したい名前に書き換えます。
   - `+` ボタンで行追加、`-` ボタンで行削除、ゴミ箱ボタンで全消去が可能です。
   - `⇄`（入れ替え）ボタンを押すと、変更前と変更後の名前を反転できます（元に戻す逆変換を作成する際に便利です）。

#### 方法2: CSVファイルから一括読み込み
1. **「CSV読込」** ボタンを押します。
2. 変更前と変更後がカンマ区切りで記載されたCSVファイル（例: 同梱の [VroidBonerename.csv]を選択します。
   - ※ 1行目が見出し（Original, New など）の場合は、「1行目をヘッダーとしてスキップ」にチェックを入れてください。
   - 文字コードは UTF-8 および Shift_JIS に自動対応しています。

### STEP 4: オプション設定
- **検索方式**:
  - **完全一致**: ボーン名全体が一致する場合のみリネームします。
  - **部分置換**: ボーン名に含まれる特定の文字列（例: `Left_` を `L_` に変更など）を一括置換します。
- **大文字・小文字を区別**: 英字の大文字・小文字を厳格に照合するかどうかを設定します。
- **頂点グループも同期**: 有効（推奨）。アーマチュアにバインドされたスキンメッシュのウェイト（頂点グループ名）も自動的にボーン新名へ連動更新します。
- **アクション・アニメーションも同期**: アニメーションデータの F-Curve パス内のボーン参照も連動更新します。

### STEP 5: リネームの実行
- 一番下の大きな **「一括リネームを実行」** ボタンをクリックします。
- ボーン名および関連データが一括更新され、画面下部に「◯ 個のボーンをリネームしました」と完了通知が表示されます。
- 万が一意図しない変更になった場合も、**`Ctrl + Z`（Undo）で一発で元の名前に戻すことができます**。
